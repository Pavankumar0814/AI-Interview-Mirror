# AI Interview Mirror

AI Interview Mirror is an AI-powered interview analysis system built using Python, Streamlit, OpenCV, and MediaPipe.

## Features

- Eye Tracking
- Emotion Detection
- Speech Analysis
- Confidence Analysis
- Cheating Detection
- Streamlit Dashboard

## Technologies Used

- Python
- OpenCV
- MediaPipe
- Streamlit
- SpeechRecognition
